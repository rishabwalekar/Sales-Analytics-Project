📊 Sales Analytics Dashboard – Power BI



🧩 Problem Statement

Businesses often struggle to understand which products, regions, and customers drive profit vs loss.
Raw sales data exists, but decision-makers cannot easily identify:

Where revenue is increasing or decreasing

Which products are underperforming

Which customers generate the most value

Seasonal sales patterns

Profit leakage areas

This project converts raw transactional data into an interactive decision-making dashboard using Power BI.




🎯 Project Objective

To design an interactive analytics dashboard that enables management to:

Track overall business performance

Identify profitable & loss-making products

Analyze customer purchasing behavior

Monitor sales trends over time

Support data-driven strategic decisions




🗂 Dataset

The dataset contains transactional sales records including:
| Column                  | Description            |
| ----------------------- | ---------------------- |
| Order Date              | Date of transaction    |
| Customer                | Customer name/segment  |
| Product                 | Product name           |
| Category / Sub-Category | Product classification |
| Region                  | Sales location         |
| Sales                   | Revenue generated      |
| Quantity                | Units sold             |
| Profit                  | Net profit earned      |





🛠 Tools & Technologies

Power BI Desktop – Data Visualization

Power Query – Data Cleaning & Transformation

DAX – KPI Measures & Calculations

Data Modeling – Star Schema Relationships




📈 Dashboard Features
KPI Monitoring

Total Sales

Total Profit

Total Orders

Profit Margin %

Sales Analysis

Monthly & Yearly trends

Seasonal performance patterns

Product Performance

Top & Bottom products

Category & Sub-category profitability

Customer Insights

High-value customers

Segment-wise revenue contribution

Regional Analysis

Region-wise sales distribution

Market performance comparison




🧠 Business Insights Generated

Identified loss-making products despite high sales

Detected regions with high revenue but low profit margin

Found top 20% customers contributing ~80% revenue

Revealed seasonal peak months for demand planning
